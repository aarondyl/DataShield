# 阶段四：部署与构建边界

## 构建边界

- `backend/Dockerfile`：保留既有 Web 托管模式；构建 React 并提供网页和 Web API。
- `backend/Dockerfile.cloud`：只复制 Python 云端法规服务，不包含前端产物；以 `RUNTIME_MODE=cloud` 启动，因此不装载租户、Product Twin、Finding、Remediation 或 Feedback 路由。
- Local 继续使用现有 Electron/PyInstaller 交付物和用户应用目录 SQLite；镜像与安装包均不得内置共享 API Key 或 LLM 密钥。

## 云端部署

生产或预发布使用 `docker compose -f docker-compose.cloud.yml up --build`。必须由部署平台 Secret 提供 `POSTGRES_PASSWORD`；该 Compose 文件不公开 PostgreSQL 端口，Cloud HTTP 端口默认只绑定 `127.0.0.1`，由反向代理显式转发。

发布必须经过人工批准，并依序执行：构建不可变镜像、运行迁移、等待 `/api/health` 健康检查、进行法规同步冒烟验证。失败时将反向代理切回上一已验证镜像；不得用 `git archive HEAD` 或整仓复制的方式上传服务器。
