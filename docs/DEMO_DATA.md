# 本地演示数据准备

产品场景使用虚构的“商户订单分析 SaaS”：商户管理员注册、上传订单 CSV，系统生成销售趋势报告。演示产品资料只在本机工作区保存。提交到 DeepSeek 或兼容 API 前，须先同意向用户选择的服务商发送本次分析需要的最少产品上下文。

全新本地数据库首次启动会从随安装包提供的法规原文导入《个人信息保护法》和《数据安全法》，并生成本机可检索的条文和结构化 Requirement。Requirement 的生命周期状态不代表人工审定；法规版本应显示 `UNREVIEWED`。来源快照和 SQLite 都保存在 `%LOCALAPPDATA%\DataShield`。

官方来源：

- 《中华人民共和国个人信息保护法》：[中国政府网](https://www.gov.cn/xinwen/2021-08/20/content_5632486.htm)
- 《中华人民共和国数据安全法》：[中国政府网](https://www.gov.cn/xinwen/2021-06/11/content_5616919.htm)

不要删除整个 `datashield.db` 来重置比赛数据，因为其中也保存法规资料和用户其他工作区。请通过工作区管理界面只删除专用比赛工作区。
