# DataShield 演示数据

演示产品是人工输入的虚构 SaaS 场景，不包含真实客户、账户、订单或商业秘密。产品描述见 [`DEMO_GUIDE.md`](DEMO_GUIDE.md)。

法规演示的权威来源限定为：

- 《个人信息保护法》：国家互联网信息办公室转载的全国人大常委会法律全文，`https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm`。
- 《数据安全法》：国家互联网信息办公室转载的全国人大常委会法律全文，`https://www.cac.gov.cn/2021-06/11/c_1624994566919140.htm`。

Cloud 导入后应保留原始来源及哈希、版本、生效日期和同步事件。自动解析的 Legal Unit 与 Requirement 必须保持“未人工核验”；不要手动编辑数据库来制作 Finding，也不要将演示产品描述成真实 AI 已验证的事实。

重置演示前，先在 Desktop 工作区管理中删除专用演示工作区。不要直接删除 `datashield.db`，因为同一 SQLite 文件也保存用户的其他本地工作区、法规缓存和证据。
